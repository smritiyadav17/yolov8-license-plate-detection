# YOLOv8 License Plate Detection

A simple project demonstrating license plate detection using Ultralytics YOLOv8.
This repository was created for learning and practicing computer vision, object detection, and YOLO model workflows.

Features

Detect license plates in images and videos
Powered by YOLOv8
Easy-to-run inference script
Basic training and testing setup


Purpose

This project was built to:
Understand YOLOv8
Practice dataset handling and model training
Experiment with object detection tasks
